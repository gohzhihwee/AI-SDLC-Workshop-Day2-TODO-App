# Product Requirement Prompts

## Low-token implementation workflow

Use [00-one-shot-implementation.md](00-one-shot-implementation.md) as the
single implementation specification for this Todo app. It condenses the 11
feature requirements into a concise build and maintenance reference.

Before changing code, read these files in order:

1. `.github/copilot-instructions.md`
2. `EVALUATION.md`
3. `PRPs/00-one-shot-implementation.md`

The acceptance checklist is authoritative for delivery. The PRP's model
routing is authoritative for selecting models. For a narrowly scoped change,
read only the relevant feature section in the one-shot PRP after the preflight
documents.
